# CertFlow DocuMate — bộ cài

Bộ cài Windows của **CertFlow DocuMate**. Mã nguồn không nằm ở đây.

- Tải bản mới nhất: **[Releases → bản mới nhất](../../releases/latest)** → `CertFlow-Setup-x.y.z.exe`.
- App đã cài tự kiểm tra bản mới: bấm huy hiệu phiên bản ở góc trên app → **Cài bản mới**.
- Cần mã kích hoạt để dùng — liên hệ người phát hành.

Mỗi bản phát hành có `latest.json` (đã ký số) để app kiểm tra file trước khi cài.
